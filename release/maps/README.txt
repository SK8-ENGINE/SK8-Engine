CUSTOM MAPS
===========

Put .skate packages in this folder.

The release includes blender_bake_showcase.skate, the first-party Blender
Feature Park demonstration. Its self-contained editable Blender source is
included beside it as blender_bake_showcase.blend.

In game:
  1. Open Settings.
  2. Select Maps.
  3. Select Refresh Map List.
  4. Choose a map and select Load Selected Map.

Changing maps restarts the current session automatically so rendering,
collision, grinds, doors, physics, lighting, and world effects all reload
cleanly. The selected map is remembered.

Only install and share other packages whose models, textures, audio, and other
embedded assets you have permission to use.
